Your agent can keep your journal now

Announcement · October 7, 2026

Dayleaf 2.5.0 opens the journal to your software. We call it Headless Dayleaf: three doors into the same calendar journal, so a script, a command line, or an AI agent can write a page the way you would — into the right planner, on the right day, with a small label that says who wrote it.

Here is the moment that made us build it. I asked Meta's Muse, from my phone, to log today's weather. A minute later a line read "Cloudy, 18°C. 7,100 steps." on today's page of my Weather planner, with a via muse chip beside it, on my iPhone, my Mac and my Android phone. I had not opened Dayleaf. The journal filled itself in, the way a good assistant fills in a paper planner left on the desk.

🧠 Why agents and journals belong together

Journaling is memory. The hard part was never writing beautifully; it was writing at all on the days you were too tired, and remembering the small facts — the weather on the day you moved, how much you slept the week of the launch, which afternoon the headache started. Agents are good at exactly the things people skip: the daily line about the weather, the steps and sleep from your watch, the screen-time tally, a two-line summary of what you shipped. Put those next to what you wrote yourself and the calendar becomes the most honest record you own.

We also wanted the reverse. An assistant that can read your journal knows what you decided and why, what you were grateful for, who you had coffee with. "What did I write about sleep last week?" is a better question for an agent than for a search box.

🖥️ Door one: a local API on the Mac

Switch on Settings → Headless Dayleaf in Dayleaf for Mac and the app serves a small API on your own computer, at 127.0.0.1:7317, protected by a token you copy from Settings. It never binds to a network interface. Anything on the Mac can talk to it: a shell script, a cron job, Claude Code, a Python notebook.

Every call goes through the live app, so an entry written this way is indistinguishable from one you typed: planners, stickers, goals, backups, On This Day, all see it.

⌨️ Door two: dayleaf on the command line, and an MCP server

Install it with npm install -g dayleaf. Then:

dayleaf add "Ran 5k along the river before work" --planner Health
dayleaf day today
dayleaf list --from -7 --q sleep --json

The same package ships dayleaf-mcp, a Model Context Protocol server. Point Claude or any MCP client at it and the journal becomes a set of tools: add an entry, read a day, stamp a sticker, tick a goal. One line sets it up in Claude Code: claude mcp add dayleaf -- npx -y dayleaf-mcp. Then you just talk: "stamp a workout sticker on yesterday."

☁️ Door three: cloud access for agents that are not on your Mac

Hosted agents like Meta Muse cannot reach a laptop. For them, Dayleaf has a cloud door on every platform: Settings → Cloud access for agents. Switch it on, create an API key, and give the agent Dayleaf's MCP URL. For Muse it is one message: "Build a custom integration to Dayleaf…" — the exact prompt is on the developer page. Muse builds the connector itself, tests it, and saves it as a skill.

From then on, what agents write lands on every device of your account, and what you write is readable by them. Agents can list your planners, add entries, search, and read a day.

🔒 What we did and did not compromise

  • Off by default, both doors. Nothing listens and nothing leaves your device until you flip a switch.
  • Text only in the cloud. The cloud door keeps a copy of entry text, dates and planner names on Dayleaf's server so agents can read them. Photos, voice notes and videos never leave your device. Switch it off and the server copy is deleted.
  • Labelled. Every agent entry carries its source and shows a "via muse" or "via cli" chip. Your words and the agent's never blur.
  • Revocable. Keys are created in the app, shown once, and revoked in one tap.
  • Nothing new is gated. Headless Dayleaf is free, on iPhone, iPad, Mac and Android.

🧪 Five things to try

  1. Tell Muse: "Every morning, log yesterday's weather and my sleep and steps into Dayleaf."
  2. A nightly cron on the Mac: curl -s "wttr.in/San+Jose?format=%C+%t" | xargs -I{} dayleaf add "{}" --planner Weather
  3. Ask Claude: "Read my Dayleaf entries from this week and write a short summary into a Reflections planner."
  4. Have an agent tick your daily goals when it sees the matching entry.
  5. Use dayleaf list --q decided --json to give any assistant a memory of what you chose and why.

What's next

Stickers and goals through the cloud door, a Dayleaf connector in Muse's directory so you can add it with a tap, and Siri Shortcuts for the iPhone. If you build something with it, tell us on the community board; the best automations will end up in these pages.
